# 확정 대기 결정

아래 항목은 데이터 모델이나 운영 절차를 크게 바꾸므로 임의로 확정하지 않는다. 안전한 기본값은 기능 비활성 또는 권한 미부여다.

## 확정된 UX 결정

- 제안 목록 기본 정렬은 최신순이다.
- 동의 모집 중에는 현재 동의를 `현재 수 / 50` 형식으로 표시한다.
- 학생 화면과 학생용 API에 정식 안건 담당 교사를 노출하지 않는다.
- 학교 공식 로고·교표·색상은 사용하지 않고 자체 브랜딩을 만든다.
- 비공개 고충 작성 경로에 구체적인 부서명이나 별도 긴급 안내 문구를 추가하지 않는다.

## 확정된 처리 정책

- D-006: 슈퍼 어드민이 최근 재인증 후 활성 교사를 정식 안건의 내부 담당자로 지정한다.
- 현재 내부 지정된 활성 교사만 공식 답변과 상태 변경을 수행한다.
- 담당 변경은 이전 지정 종료와 새 지정을 모두 보존하며, 학생 UI/API에는 담당·응답 교사 정보를 노출하지 않는다.
