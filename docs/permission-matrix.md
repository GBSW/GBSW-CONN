## 서비스 계층의 필수 재검증

- 인증 주체의 활성 상태와 세션 유효성
- URL의 공개 ID가 가리키는 객체에 대한 객체 수준 권한
- 현재 역할과 보직 임기 또는 사건에 저장된 심의자 스냅샷
- 민감 작업의 최근 재인증 시각
- 이미 투표했는지와 사건이 최종 결정되었는지
- 요청 DTO에 작성자 ID, 역할, 동의 수, 감사 필드가 포함되지 않았는지

정식 안건 담당 교사는 슈퍼 어드민이 최근 재인증 후 내부 지정한다. 지정·변경은 이력을 덮어쓰지 않으며, 현재 지정과 활성 교사 역할을 서비스 계층에서 함께 재검증한다. 학생 화면과 일반 학생용 응답 DTO에는 담당·응답 교사의 이름, 로그인 ID, 내부·공개 UUID를 제공하지 않는다.

비공개 고충 담당자는 학교 결정 전까지 권한을 부여하지 않는다.

사건 생성 시점의 학생부장교사·학생회장·학생부회장을 사건별 심의자로 고정한다. 이후 보직 임기가 바뀌어도 기존 사건의 목록·상세·의결 권한은 스냅샷을 기준으로 판단하고, 새 사건 생성 권한은 현재 학생부장교사 보직을 기준으로 판단한다.
